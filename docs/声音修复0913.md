## 界面可调用接口

| API | 行为 |
|---|---|
| enableSound() | 显式解除静音并尝试解锁，保留总音量/分组设置，包括零值 |
| preview(cueId = hit_heavy) | 预加载指定片段后走真实混音通路；返回是否已发起播放；不自动重试错误或恢复默认 |
| cancelPreview() | 取消未完成及已播放的试听，不停止同名战斗声音或环境声；设置/标题关闭时调用 |
| retryFailed() | 只重试失败采样；返回 fetched/decoded/failed |
| restoreDefaults() | 仅用户主动按钮调用，恢复总音量0.6、音效0.8、语音0.9、环境0.3和非静音 |
| settings() / hudState(group = sfx) | 返回设置快照/当前分组状态；文案用 sfxHudText |
| setDiagnosticsEnabled(bool) / diagnostics() | 控制有界日志和分析器，返回实际pending、错误、正在播放和电平 |

hudState的 ready 仅表示指定游戏声音通路当前没有已知阻塞；不表示未核验语音已补齐，也不表示每次都使用采样而无回退。采样/合成累计播放分别留在诊断。
