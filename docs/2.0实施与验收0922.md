## 已实现

两名角色各9个独立快捷技能，默认一键模式关闭搓招识别；双人分别选模式，支持混用、分页改键、保留经典存档及独立教学进度。技能沿用核心四帧缓冲、命中定格、耗气和取消检查，失败不降级为另一招或普通攻击。暂停、出招表和掉焦清理未释放输入。

技能栏提供真实按键、名称、耗气及不可用原因。选人短回应、回合/Fight/KO播报和字幕接入统一声音通路；日常短句四秒站立、两秒无接触、每角至少二十秒间隔，全场低优先级一次一句。换回合保留间隔，暂停与换回合清除连续待机积累。文字颜色未改变时不再重绘技能栏文字纹理。

选人回应复用用户以前认可的声音；新增播报是已安装的Microsoft Zira Desktop合成英文，绝非拳皇或人物原声。新口头禅和专属喊招尚未正式采用，见下方缺口。

## 加载与性能追踪

新增播报和已采用选人短回应合为72,304字节派送包，保持所有美术/音乐派送记录不变，避免菜单阶段提前下载完整人物语音银行。选人完成后，在加载场景切换到原有战斗曲，避免继续下载即将离开的菜单曲；歌曲、音量、暂停与混音设置不变。

初版三次5Mbps/150ms首拳25.09—25.34秒，超过25秒目标。重打音频包后仍存在24.29—25.06秒波动；后续冷启动还有25.70秒，不隐去失败结果。

最终 `index-B4BjPNrS.js` 在5Mbps、150ms、隔离Edge冷缓存条件下的三次结果：菜单3.520/3.017/3.036秒，首次普通拳24.958/24.405/24.302秒，均通过菜单≤4秒、首拳≤25秒；第一组同资料热重访5.019秒。三次无页面错误，声音ready。证据 `acceptance/loading-battle-stream/`。这些只是本机受控结果，最慢一次接近目标边界，不保证任意大陆线路均能达到。

最终构建在独立、可见且持续取得焦点的Edge窗口运行900.019秒，完成14场有限血气人机，交替使用两角色、重赛与重新选人，页面错误为零。证据为 `acceptance/perf-20260922-033540/result.json` 与 `summary.json`。

浏览器回调频率受本机屏幕刷新和浏览器调度影响，不是游戏逻辑频率，也不直接等于显示器实际呈现帧率。15分钟脚本每场结算抓取一次截图，另做同构建、无截图测量的实际胜利比赛：路飞简单人机2:0，进入Result后等待1.5秒才停止测量并截图，结算最大回调间隔10.0ms、全程超过50ms为0次（`acceptance/local-final-20260922-035345/`）。这支持此前14次长帧主要来自截图取证的判断，不以一次复查证明所有机器均无结算卡顿。

带声对照录像早于最后的跨回合语音间隔与菜单曲下载时机修正，人物、美术、键位和歌曲与最终构建相同；最终公网整场录像另存。

第一次性能检查因发现跨回合台词间隔问题在约90秒主动停止，明确不算十五分钟验收。最终需同时记录浏览器回调间隔、逻辑帧、资源、音乐实例和多次重赛；无界面模拟频率不能证明浏览器帧率。
