# 2.0键位与回退说明0922

2.0默认使用一键技能。移动、普通拳脚、防御、翻滚、投拆维持原规则；一键只省去搓招，仍需要气量、正确的空地状态和合法取消时机。

## 默认操作

P1：W跳、A/D左右、S蹲；J轻拳、K轻脚、U重拳、I重脚；L翻滚、O吹飞。按后方向防御，贴身前或后加重拳投技。Enter或Esc暂停。F11查看当前角色、朝向与键位对应的出招表。

P2方向键移动，小键盘1/2/4/5为四个拳脚、3翻滚、6吹飞。设置里的“P2使用无小键盘布局”同时将普通拳脚改成N/M/逗号/句号、翻滚改成斜杠、吹飞改成右Shift。此时M不再触发静音，请在设置中调整声音。

一键模式下不识别搓招；移动后按普通拳脚不会误出特殊技。技能按住不自动连发，同时按多项取表中靠前的一项，不可用时不改成另一招。技能栏显示真实耗气和不可用原因，没有额外冷却时间。

## 切换与改键

- 选人时按该玩家的重拳切换“一键技能/经典搓招”。双人可以混用，电脑与训练木桩保持原输入方式。
- 设置→P1/P2键位：技能键分三页，支持改键、默认值和冲突提示。Enter、Esc、Tab和F1—F12为系统保留键。
- 比赛中修改操作模式从下一场生效，包括重赛；键位保存后生效。经典与一键的键位独立保存，原经典键位不会被新布局覆盖。
- 本轮手柄使用经典模式；一键技能的验收范围为桌面键盘。
- 教学跟随当前模式，特殊技必须真的打中；打开出招表、暂停和掉焦会清理未释放的输入，回来不会补出旧技能。

## 两种回退的区别

| 入口 | 含义 |
|---|---|
| 2.0内选择经典搓招 | 使用2.0界面、声音调度，恢复传统输入 |
| 开始1.0经典版.cmd / 公网v1/ | 冻结0915完整动漫版，代码、素材、声音和CPU均来自原版本 |
| 开始旧版游戏.cmd | 更早的像素版，不能称为1.0动漫回退 |

本地入口只启动已有构建，不安装依赖、不构建、不自动发布。首次克隆源码不会取得被忽略的正式游戏素材与本地构建。
