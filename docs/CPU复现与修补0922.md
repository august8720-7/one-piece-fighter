# CPU复现与修补0922

结论：复现成立，候选不合入，正式 CPU 保持原样。释放持防候选没有改善路飞反复重拳对普通赤犬的问题，正常进攻对照还有退步。本轮不改难度概率、反应延迟、角色策略权重或战斗数据，也没有恢复0913撤回的快招优先。

## 文件与证据约定

`scripts/cpuAudit0922.mjs` 为可复现检查入口。`.local-releases/操作演出-0922/acceptance/cpu/<时间>/` 保存本次 CPU 源码快照、候选源码、逐帧首差异与汇总 JSON；新运行使用新目录，不覆盖旧结果。先记录来源清单与哈希，再保存源快照并核验。候选通过配对检查后才考虑进入 `src/ai/`。

对照使用双方角色、左右换边和固定种子；重复重拳、正常进攻、防守与跳入分别统计。左右镜像不是独立样本。普通投抓到与实际伤害分别记录；胜率不作为主观好玩的证据。

## 复现条件与结果

正式证据目录为 `2026-09-21T18-44-24.276Z/`（目录名为UTC，对应北京时间0922），其中 `paired.json` 保存全部480组配对、每组首次输入差异前4帧后44帧、种子1重拳首次命中轨迹、命中伤害和原归档匹配结果。每组分别运行原版和候选，共960场；30种子×两角色×左右两侧×四种策略，普通难度，99秒、先赢两局，最多36000帧。此前小样和首次报告均保留，不计入独立样本。

脚本策略：

- 重拳：距离大于140像素则接近，否则世界帧号为10倍数时按一帧C，其余归零；与0913原实验相同。
- 正常进攻：玩家侧使用原版普通CPU，种子为当前种子加1000；不是人类随机操作。
- 防守：每180帧的前140帧蹲防，其余时间距离大于90像素则接近，否则每12帧按一次C。
- 跳入：地面距离大于180像素则接近，否则每45帧前跳；空中每10帧按一次C。

120场原版重拳样本的胜负及比赛帧长全部与 `.local-releases/改造验收-0913/cpu-heavy-timing-before0913.json` 一致。以下均为玩家胜场，每格60场，左右样本有关联：

这些是固定脚本下的结果，不估计所有玩家的胜率。尤其防守和跳入脚本本身较弱，CPU全胜不能证明CPU好玩或这些打法不可行。

## 逐帧定位与候选边界

【事实】原版路飞P1、种子1：80帧玩家按C；81帧CPU观察到新起手并选中延迟防御，安排93帧执行；89帧路飞重拳已经命中，CPU损失80血。此时没有“过期持防”可释放。这段首先说明12帧反应晚于本次首次打击，不能把防御提前到命中前称为不改难度的修复。它不能单独解释整个45/60结果。

【事实】持防分支确有在对手不再构成近身威胁时继续占用输入的样本。例如玩家赤犬P1、种子10的120帧，路飞CPU已可行动（蹲姿），对方重拳处于28帧，原持防还剩16帧。候选当帧释放持防，从后下方向输入改为0；它没有自动强制快招或投技。

候选只在对方仍为攻击状态、当前不构成近身威胁且观察已满原反应间隔时释放已有防御。它未改概率、未读取玩家输入，也未采用确反优先。但“没有近身威胁”不等于“应该立即停止防御”：主动预判、飞行道具与后续进攻仍可能需要持防。因此报告指标命名为 `guardFramesWithoutMeleeThreat`，不把全部统计帧称作错误。

这项指标在重拳赤犬玩家组由278帧降至55帧；但路飞玩家组虽然从8降至2帧，两版CPU总伤害同为117866、玩家总伤害同为142920，胜负不变。它并未触及主要重拳问题。

【事实】全局存在退步：赤犬重拳种子26、29在左右两侧均由CPU胜变玩家胜，种子21、22、24则相反。正常路飞进攻组玩家胜6→7，不能把改良赤犬对照的28→26当作稳定收益。跳入赤犬组CPU胜场虽相同，CPU总伤害130803→130179、玩家伤害26520→26540。伤害合计受比赛时长、局数影响，不将这些总数解释为局部因果。

【决定】保留原CPU；没有可靠依据恢复快招优先、增加反应速度或继续搜索参数。尚未解决的是原重拳策略的稳定收益。

## 有限追加：距离与恢复调度

按主代理追加要求，独立检查相同120场原版重拳样本，不改变任何策略。`scripts/cpuSpacing0922.mjs` 保存每次中立决策、CPU恢复可行动时的输入/队列/决策间隔，以及已观察威胁下的前进帧。证据为 `2026-09-21T18-47-38.542Z-spacing/spacing.json` 与依赖源码哈希清单。

- 两角样本中，“CPU可行动、已观察对手至少12帧、近身威胁仍在、却输出纯向前走”的帧数均为0。这不能排除其他玩家打法，但本策略下没有找到继续走入已知威胁的具体错误。
- 路飞重拳组：赤犬CPU共2985次从非中立状态恢复可行动，2985次当帧重新决策，没有额外空等一轮反应的调度错误。
- 赤犬重拳组：路飞CPU恢复可行动3058次，其中3052次当帧重新决策，其余有已持有/排队的有效输入；两组“未新决策、无输入、无持有/队列”的恢复空等均为0。
- 对方收招时，路飞玩家组的CPU决策包含普通打击39次、特殊技54次、走路18次、等待12次、防御2次。这些是既有混合权重与意愿选择，不等于存在非法丢失决策。单凭某次等待后受击，不能把它改成必定攻击并仍声称难度和策略未变。

因此没有再制作第二个候选；未凭猜测新增过去动作记忆或提高预判防御。后续改善需要明确的策略设计及局部因果验证，本轮诚实保留未解决。
