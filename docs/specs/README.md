# 功能规格与重建数据

唯一入口为上级 `项目功能手册.md`。本目录保存按模块拆分的行为规格、经核对的机器可读数据快照及其来源指纹。正文须区分当前行为、用户确认的目标、设计初值、已知缺陷和待验证项；文件名沿用“主题+MMDD”。

- 规格说明输入、状态、输出、边界、依赖与可观察验收，不能只指向旧代码。
- JSON快照保存角色/招式/输入等原值及数据字典，供脱离原实现重建；有未提交修改时不能只写Git HEAD。
- 旧快照保留；同轮变更在手册和进度中指向新证据，不修改历史核验事实。
- 原图、声音、模型、验收媒体及大文件仍归D盘项目资源/发行根，不放进本目录；引用须说明能否随源码取得及缺失风险。
- 本项目所有新文件、缓存和临时产物仅写D盘。运行命令用项目根 `run-d1013.ps1`。
