# CPU配对审查与回退0913

结论：撤回本轮新增的“按剩余收招优先选择快招”策略，保留此前CPU。固定样本73→77不能直接说成随机噪声，也不能用更多收招接触来抵消退步。配对审查发现普通投被错误优先的明确原因，修正一次后仍未得到足够的保留依据，按一轮审查的停止条件收尾，不继续追逐胜率。

## 同种子逐项复现

重新加载归档旧CPU与候选CPU，使用同一当前核心、角色数据及输入策略分别运行120场。双方全部结果和帧长与既有记录吻合；80场逐帧CPU输入完全相同。胜负翻转12场，全部发生在玩家赤犬对普通路飞，实际为6个种子的左右镜像：10、17、25、29从CPU胜变玩家胜；14、15从玩家胜变CPU胜。不能把左右镜像当作12个独立样本，也不能据此估计所有策略下的总体胜率。

## 可确定的选择错误

5个种子的首次差异都把原打击改成普通投。原筛选把抓取当0帧接触，却忽略普通投抓到攻击收招后仍可由后续输入拆投。玩家原本每10帧一次的C会恰好拆投；这不需要读取或修改未来玩家按键，规则本身就允许发生。

为区分局部原因与之后随机决策变化，重放首次差异前的完全相同输入，仅执行那一次CPU动作的已排队输入；此后CPU输入归零，玩家继续原策略，观察90帧。此隔离实验不是正常CPU强度测试：

- 种子10、14的原回旋弹各造成201伤害，普通投均被拆、造成0伤害，随后CPU吃80伤害。
- 种子15、25的原重拳各造成80伤害，普通投均被拆、造成0伤害；两边后续均会吃80伤害。
- 种子29原机关枪造成110伤害，普通投被拆、造成0伤害，随后CPU吃80伤害。
- 种子17第一次选择机关枪反而带来局部收益：126伤害且不受击，对照重拳92伤害并之后吃80。整场却翻为玩家胜，说明首个局部接触收益不能代表整场收益，更不能简单归因于被动。

上面5组中14、15的完整候选比赛最终反而获胜，也说明后续路径变化会掩盖首次选择的局部劣势。因此本轮结论以已复现的普通投优先错误和缺乏稳定收益为依据，不把所有输赢翻转强行归于一个机制。

## 仅一次定向修正及决定

修正实验只取消普通投的确反优先资格，普通投仍保留原混合权重，不改伤害、时长、距离、AI难度或概率。新增真实模拟器回归证实：普通投抓到收招后仍可由随后C拆投，伤害为0。57项既有候选AI测试加此1项均通过。

同一120场再次运行，玩家胜场为79/120：路飞P1/P2仍23/22，赤犬P1/P2为16/18。这个结果仍不支持把整套时机优先策略作为已改善CPU的正式改动。到此停止修改策略，恢复本轮前源文件和测试；候选的时间边界与普通投发现仅留作复审材料。
