# 声音修复交付0914

状态：实施及实机验收中，尚未更新公网。目标是修复走路、等待、普通攻击缺少人物声音以及没有背景音乐的问题，人物、美术、伤害、判定、招式时间和AI不变。

## 已接入

- 路飞、赤犬各两句日语待机短句，连续站立后触发；两人交错，后续至少间隔18秒。出招和受击取消本人的闲聊；暂停和掉焦不累计待机时间。
- 移动、冲刺、跳跃共用日常出力冷却，至少间隔12秒；普通拳脚增加短出力，连打有独立限频。路飞复用两个已确认短出力变体，赤犬目前一个，没有拿未核验片段凑数量。
- 两角各三个脚步片段，跟随实际移动和可见动画落脚帧；撞墙不移动、停步、空中不播放地面脚步。
- 菜单及选人一首、战斗及训练一首、胜负短收尾各一段。音乐流式播放，走既有 AudioContext、分组和总音量通路；切曲最多两份，常态一份。
- 菜单到选人连续，同一比赛换回合不断曲；暂停、静音和零音量停止输出，恢复时从原位置续播。人物说话时音乐降低约6dB，之后平滑恢复。
- 设置增加背景音乐音量、人物/音乐试听和停止试听，保留旧静音及三个原分组设置。音乐或人物资源失败有对应说明和重试；公开包显式收集所有新增文件。

## 素材和听感边界

正式清单为52个音效配置、14个人物语音配置、1个环境配置，以及4个音乐播放配置；短音70个不同文件，音乐4个文件。四句新增待机和展示配乐已由用户试听并回复“人物短句和配乐都可用”。来源和处理依据见[日常声音与音乐来源0914](assets/日常声音与音乐来源0914.md)，许可署名见[声音素材署名0914](assets/声音素材署名0914.txt)。

用户确认不扩大为全部曲长、循环接缝或成品混音均已满意。当前工具未提供代理可听辨的回传，因此代理没有宣称自己听辨了日语语义或成品音乐；浏览器实际音轨、输出电平、解码检查和真人评价分别记录。
