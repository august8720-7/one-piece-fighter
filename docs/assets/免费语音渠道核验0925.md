# 免费语音渠道核验0925

查阅日期：2026-09-25。对应 `docs/四角色桌面与手机联机目标0925.md` 的两角原创萌系配音。此记录只证明公开入口、界面、公开配置与条款；本次研究没有登录、提交生成、消耗额度或下载新音频。实际短样制作由主代理另行记录，不能把这份记录计入语音完成数量。

## 结论

**首选试产：Qwen 官方 Qwen3-TTS Hugging Face Demo 的 Voice Design。** 已在内置浏览器实际打开完整可交互界面，支持中文文本和自然语言音色描述。原始输入不需要真人参考声音，适合为 LABUBU 与星星人各设计一条原创声线。官方仓库直接链接此 Demo，来源关系已核实。

不凑第二站。本项目应先对这个已打开的入口做一条短样的生成、试听和独立下载验证；本轮只有入口核验，没有成功音频交付证据。若实际免费额度或服务不可用，应保留具体错误再转其他合法免费渠道，不能据此停止其他工作。

- **【事实：网站】**[HF 服务条款](https://huggingface.co/terms-of-service) 的 Your Content 部分写明 “You own the Content you create”，同时要求使用者有权提供输入、不侵犯第三方权利；附有许可的内容仍按其附属许可处理。网站保留服务调整/中止权，没有免费服务持续可用保证。这里记录的是已查文本，未执行新的条款接受动作。
- **【推断：本项目采用】**使用本游戏原创短句、文字描述新卡通声线、保留生成来源和用途，不克隆真实配音演员，不直接拿站点示例音频入包；已查材料未见把该用法限于研究或非商业的条款。因此它适合进入本项目的正式素材候选流程，完成生成、听辨、下载和来源记录后再决定采用。
- **【不知道：输出权利的剩余范围】**本次未找到 Qwen Demo 对“每条输出音频的可再授权方式”单列、比 HF 通用条款更具体的声明。不能因此保证成品具有排他著作权、零相似性或可替人物 IP 再授权。公开源码许可证与采用的音频来源说明继续分开，不能给全部声音统一写“任意商用/无版权”。

## 首样验证交接

1. 主代理已接手官方 Demo；优先 `Voice Design`、语言 `Chinese`，分别用已批准的原创短句和两角音色描述。先一条，不上传项目文件，不充值或切付费账户。
2. 记录提交前界面、任务状态、实际免费余额/配额错误、是否成功返回音频和耗时；短样按实际输出切分，不能把生成成功提示当可听成品。
3. 真实播放听辨原句、音色、无 BGM/杂音、短促出力是否自然；检查输出的独立下载，保存原字节、来源/模型/提示词/时间与 SHA256。首次试听仅能证明该条短样。
4. 小样通过后，用已选参考声线延续其他短句，并记录是否保持一致；若设计模式每次音色漂移，不靠混剪跨音色凑数量。
5. 免费 GPU 不足时保留错误，不买点数、不多账号规避。正常使用用户已有免费账户若触发验证码或现场条款步骤，由用户处理该必要一步，其余制作继续。
