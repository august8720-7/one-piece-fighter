## 确定性加工与事件映射

可复现脚本：`scripts/prepare_audio_assets.py`。依赖 NumPy、soundfile 及 FFmpeg，仅安装在系统临时目录。本轮命令：

```powershell
python scripts/prepare_audio_assets.py --deps "$env:TEMP/opf-audio-python-0911" --ffmpeg "$env:TEMP/opf-audio-python-0911/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v7.1.exe"
```

源文件只读。单段先去直流、必要时去静音，按源时间裁切，变速会同时改变音高与时长；FFT 平滑高/低通不产生新的声源。各录音分量按峰值和配置增益组合，成品再规范峰值并短淡入淡出；没有振荡器、合成噪声或生成式音频。源码列出完整参数，下面的区间是实际源录音区间，单位秒。

`start/release/end` 分别对应蓄力、实际发力/发射、合法结束事件。多段短音受播放引擎实例与冷却限制；清理回合不播放落地爆炸。环境 20 秒首尾淡化，录音内的袋子声来源页面已披露，是否适合舞台仍待试听。
