# 网络素材编码0915

本轮仅重新编码已有素材，没有生图、补画或更换声线。GPT Image 2.5 原始生成记录、原图、PNG 图集、原声音及来源包均保留。

## 发布清单与复现

- 母版：`public/assets/characters/*/anime/`、`public/assets/fx/`、`public/assets/stages/marineford/`、`public/assets/audio/`。
- 衍生文件：`public/assets/delivery/`，文件名包含内容 SHA256 前20位，完整哈希和母版映射在 `src/render/deliveryManifest.json`。
- 当前素材版本：`f7f18b311205945e28e1174885f89df03ebe382b11d9f0909afb69391d16a59f`。
- 复现命令：`python scripts/build_delivery_assets.py --quality 93 --ffmpeg <已有ffmpeg完整路径>`。使用 Python 3.14、Pillow、NumPy 及现有 ffmpeg 7.1；不安装全局依赖。
- 构建命令：`npm run build -- --mode delivery --outDir <新的候选目录> --emptyOutDir false`。交付模式只输出显式清单，原图和原声音包不进入公开构建。

生成脚本校验人物母版的 build-report 哈希、界面人物哈希及音乐原始来源哈希，再处理素材。每份衍生文件记录来源路径、原文件哈希、编码后长度和哈希。短音 Ogg 使用 bitexact 输出，消除容器随机序列号；连续两次生成的三份短音银行及未改参数的音乐文件哈希一致。临时音频保留供复核。

## 图像

赤犬投技和冥狗的24个主体／前景帧单独放入无损 WebP 页。逐帧解码后，它们与原 PNG 裁切的 RGBA 完全一致，因此原先的主体加前景组合像素保护继续成立。普通帧的 alpha、所有帧的尺寸、动画曝光时序、根点及连接点全部保持一致。

## 声音

70份既有 WAV 各自编码为独立可解码的 Opus 96k 片段，再按公共音效、路飞、赤犬合并为三个下载银行。每段均有准确字节偏移和长度；播放前从银行切出完整编码文件并独立预解码，不用连续音频时间切片，不会因邻段编码延迟串音。

- 三份短音下载银行合计646,524字节，保留全部70份短音及原事件映射。
- 菜单音乐使用 Opus 80k；战斗和两份结算音乐使用 Opus 96k。均从既有已核验的来源录音重新执行原截段、响度与淡变处理，不对上一版有损交付文件重复转码。
- 菜单162秒、战斗89.6秒及两份结算片段保持完整。音乐继续流式播放，经过原音乐分组和总音量；保留暂停、静音和独立音量设置。
- 署名继续交付 `assets/audio/music/CREDITS.txt`。音乐来源与许可见[日常声音与音乐来源0914](日常声音与音乐来源0914.md)，日语语音的原人工确认没有被扩写为本轮新听感确认。

本机对70份短音和4份音乐分别解码到48kHz PCM：74份长度与原交付声音一致；最大 RMS 音量差约0.77 dB，没有新增超过满幅的样本文件。完整逐文件数据见 `audio-encoding-audit.json`。这些是解码、时长和波形证据；不能单独证明人耳听起来完全一致。浏览器真实混音录音与用户主观听感分开记录。

当前27个唯一发布衍生文件合计14,593,325字节，包含全部音乐，未包含页面、引擎和显式旧版回退。实际首场传输量和完整公开包大小见本轮交付记录，不能将此数与旧版仅到标题的传输量混用。
