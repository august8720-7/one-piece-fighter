## 路飞击飞、倒地与起身：五张新姿势

最小组合建议是**两张空中受击、一张倒地、两张起身**。另画与附件一致的中立参照，仅用于整张来源的尺度校准。不能把普通站立受击抬高、旋转后当作空中原画，也不能把蹲姿简单缩矮当倒地。

| 用途 | 新姿势 | 根点与身体关系 |
| --- | --- | --- |
| `hit_air` 0 | 刚被击飞，胸腹受冲击、上身后仰、双脚离地，手臂失去护架 | 使用原中立的虚拟角色坐标，不按两脚最低点重新居中；由core的y坐标抬高整个人 |
| `hit_air` 1 | 空中侧倒、腿部自然收起的过渡姿势，可用于抛物线运动和墙弹后继续飞行 | 保持与上一画可衔接的骨盆位置；不要画成只适合向上跳或只适合俯冲的极端姿势 |
| `knockdown` 0 | 已落地侧躺／背侧着地，重心低，肢体完整 | 虚拟root位于骨盆附近的地面投影；身体落在地面上方，不能继续悬浮或穿地 |
| `getup` 0 | 一掌撑地、身体翻向单膝承重，真正从倒地起身 | 手／膝／支撑脚与同一地面线相接，root保持同一世界位置 |
| `getup` 1 | 双腿重新承重、半直立并收回护架，接现有中立站姿 | 根点与idle一致；站高随姿势恢复，身体尺寸不变 |

### 拟用取帧配置与分支

- `hit_air`：`frames:[air_impact,air_tumble]`，`exposures:[{frame:0,ticks:6},{frame:1,ticks:1}]`，`loop:false`。第6帧以后保持第二画，直到core实际落地或重新受到打击。这里的1只是让最后一画进入保持状态，**不表示只飞7帧**。6帧的过渡点是待实机调整的视觉建议。
- `knockdown`：`frames:[down]`，`exposures:[{frame:0,ticks:36}]`，`loop:false`，与现有36帧倒地对齐。
- `getup`：`frames:[rise_support,rise_guard]`，`exposures:[{frame:0,ticks:7},{frame:1,ticks:7}]`，`loop:false`，总14帧，结束后由core转回已有idle。

`hit_air`没有固定结束帧。它受实际落地位置、初始高度、再次命中和墙弹影响；墙弹会改速度，但当前实现不重置`stateFrame`，所以不能把一个固定时刻写成永远正确的“到顶开始下落”。第二张采用方向中性的空中受击姿势，正是为兼容这个现状。若实机需要明确的墙面撞击或上升／下降分画，那是后续独立的表现需求，不在此稿伪称已有支持。

大喷火未设硬倒地。路飞落地时若仍按攻击键，现有core允许直接进入`getup`，跳过36帧`knockdown`；样板人控输入仍可能出现这一分支。因此起身第一画也要能从低位落地受击衔接，不能只适用于长时间平躺后醒来。不能为了展示倒地图而修改该规则。

### 根点和来源尺度怎样落到清单

所有帧共享同一来源内角色尺度：新图中立可见高度为H源像素时，路飞`source.unitScale=796/H`，`character.scale`仍为0.22。H必须等原图下载后实测，当前值为**未取得**。不用每张受击图各自的外框高度反算比例。

每格先保留同一个虚拟root坐标与中立参照，逐画记录裁切框、root、肩和腕；必要时额外记骨盆点便于检查。裁切之后，`root_in_crop=虚拟root在原图中的坐标-裁切左上角`。空中帧root允许在可见身体或裁切外，不能强制移到脚底最低像素。

屏幕位置始终是`core给出的角色根点 + (原画上的点-root) × 统一缩放`。core负责整个人飞出去和落回地面，原画只表达弯腰、收腿、翻身等身体相对根点的变化。未来各画的实际骨盆／脚底偏移要在成图后逐一量取；此稿不预填不存在的坐标。重点检查空中末姿→倒地、倒地→撑地、半起身→idle是否出现瞬间横移、悬浮或缩放。

## 使用门槛与待验证项
