# 路飞短臂回收方法调整 0912

首稿、一次伸臂返工和局部直段配准已解决袖口连接与出拳范围，但真实回收原画的拳前缘约258.30屏幕像素，下一张归位姿势仅61.40，最后一跳约196.91。仅重新分配16帧收招或在前半段压缩直臂都不能填补这段身体动作；把长弯臂按直线压缩也不符合当前加工边界。

本次改变制作方法，**只补缺少的短臂回收关键姿势**，不再要求模型重画整套待机/起手/有效/回收表。以已取得的母版和伸臂返工原图为参考，将拳前缘由长弯臂后的约160、100逐步回到65屏幕像素附近，画真实弯肘与身体收势，固定普通人体比例和落脚。生成后依据实际画面量取根点与连接点，不把提示词坐标当作模型已遵守的事实。

所有新增原画继续由可核实的官方GPT Image 2.5入口生成，保留提示词/原始下载/来源/采用与失败状态。原有两轮素材与几何处理不删除。新画合格后只重排原16逻辑帧收招，不改9起手/4有效/16收招和任何判定。

这是对已定位缺失姿势的有限补画，不是第三轮相同整表生成；若仍不能得到真实连续短臂，不扩产其他动作，提交具体失败对照与下一步方法判断。
