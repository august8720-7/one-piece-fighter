# 大喷火局部校准方法 0912

首稿六格中，第2/5格与第3/4格换能力手；统一中立尺度后的实体拳前缘约281屏幕像素，原判定前缘为360。一次定向返工已把能力手统一在画面右侧肩部，但最长拳仍约为旧长度比例。两份原图都保留，不开始第三轮同类整表生成。

继续试验的变量缩为**已有熔岩前臂的长度配准**。人物普通身体、脚点、正常上臂、肩袖、非能力手、巨拳本体均不变。只在原图已经画成连通熔岩材质的中段做明确的离线横向重采样；末端拳保持原始大小和平移。不会画新肢体、增加拳头、生成新光团遮缝，也不扩大伤害范围。

这与把整人放大有本质差别：普通身体和脚不参与变换，主体轮廓仍来自指定模型原图。它仍可能造成岩壳被拉长的材质问题，因此先输出原图/处理图/真实判定的并排对照，在游戏实际尺寸检查后才决定采用。不能把机械哈希通过视作美术通过。

实施顺序：

1. 以返工左上中立姿势高度确定整张统一尺度，人工量取普通身体边界、熔岩段起点、腕/拳边界与根点，并注明坐标为人工配准。
2. 仅对熔岩段做水平方向的比例调整，使实体最前缘接近当前根点右侧360屏幕像素；拳心高度目标约-150，现有高度已接近，不任意改动。
3. 若画布宽度不足，只增加透明边距；保护区像素必须前后相同，末端拳只做整像素平移以保持像素形状。
4. 检查肩袖—熔岩—拳的透明连通、拳数量、边缘、保护区哈希和对应攻击走廊。先出正常速度对照，再接20起手/5有效/32收招的原时长。

该方法是双机制样板的有限加工试验，未通过之前不声称大喷火完成，不扩为通用动作补帧，更不把原判定改成迁就图像的范围。实际坐标、参数、原图SHA256和采用结果由加工凭据补充记录。
