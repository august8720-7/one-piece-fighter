## 待判别，不能冒充根因

1. 用户看到的是旧像素回退，还是新人物经缩小和画布放大后仍显得粗糙？可能并存。需要运行纹理key、animeErrors、画布/显示尺寸和实际游戏截图，不能只看大原画作答。
2. 新人物加载用了`crypto.subtle.digest`；页面实际安全上下文、资源加载/校验和预览环境应检查。不能从用户点了“网页预览”入口就断定沙箱或iframe一定造成回退。
3. 全无声可能涉及持久化的`opf.audio.v1`（muted、volume、groups）、AudioContext状态、暂停/逐帧/出招表状态、标签静音或输出设备。用户已经能出招时，“没有点击解锁”不应成为未经检查的唯一解释。
4. AudioEngine的HUD主要检测muted/context状态，音量为0时可能仍显示就绪；resume失败也缺少明确诊断。应设计用户看得懂的资源与音频状态，而不是增加一整屏开发者标签。

本次浏览器连接工具两次均报`failed to write kernel assets: 系统找不到指定的路径 (os error 3)`，未取得用户当前标签页/音量状态。没有把旧测试窗口数据当成用户当前状态，没有更改系统设置或擅自重置用户音量。
