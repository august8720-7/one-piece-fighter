## 1. 结论

GPT 大方向对：朋友能反复玩的 1v1；锁路飞 / 赤犬、单舞台、本地对战 + 人机 + 训练；先修 AI 和可玩性，不加角色、不做联机。

中间必须正视的问题不是「不会 3D 建模」，也不是「像素风还不够统一」。

**缺的是 2D 连续动作帧。** 仓库里只有四张设定图（`sheet.jpg` + `moves.jpg` × 两人）。这是静帧概念图，不是精灵表。走路、蹲走、受击循环、橡胶气球在图上不存在。图集里 137 / 113 个帧名，只是同一批静帧换名字。

因此：

- 不能再把「动作连贯」做成程序画 40px 色块人换图集。GPT 后来已经把这条写进 `AGENTS.md`：辨识度不得低于当前设定图基线；先验收单角色正常速度样板。
- 不走 3D 建模 / MMD 预渲染。`PLAN.md` 第 2.4 节已经否过；本项目也没有建模管线，学建模解决不了本周试玩。
- 现有 JPEG 抠不出走路。技能可以继续用图上已有的大图姿势做更好的分配，但分配不等于动画。
- 真要走路和技能连续播，只能另接一套带帧的 2D 精灵（NDS / 3DS / MUGEN，本地、不进 Git），先做路飞站立 / 走 / 拳 / 受击样板，你点头后再换赤犬。

来源只有这四张图。已切出的大图姿势：

| 角色 | 图上真实姿势 | 逻辑在用、但图上没有的 |
|---|---|---|
| 路飞 | 站立小图、英雄立绘、短拳、伸臂拳、机关枪起手/拳雨、起跳、腾空、下砸、火拳蓄力/突进、倒地=站立旋转 | 走、退、蹲走、受击循环、气球、二档蒸汽 |
| 赤犬 | 站立、蓄力、前冲拳、威压、大特写拳（只当立绘）、熔岩刺拳、上勾、地裂、举手、召唤、倒地=站立旋转 | 走、退、真蹲、受击循环、熔岩化专图 |

当前映射里已经在「假装」：

- `walk_fwd` / `walk_back` = `idle`（站姿平移）
- 路飞蹲技共用 `redhawk_charge`；气球 = 站立
- 赤犬轻蹲技曾经整段停在蓄力；跳 / 防 / 受 / 胜 大量共用 `intimidation`

这不是切图脚本偷懒，是源图没有对应画面。再抠边缘、再生成像素人，都变不出走循环。

`assets-src/characters/*/pixel/` 仍在磁盘上，是未采用的历史试验，正式生成不得读取。
