# 传奇七角技能设计1003

2026-10-03。本轮为已授权新增七角的数据候选；总23人阵容由主代理集成。本文不代表七角已有原画、声音或已成为公开可玩角色。

## 复用与规则边界

复用现有Phaser/60Hz FightSim、`attack/normal/utility/throwMove`构造器、Cpu按键编译器。0929已完成底座开源调研，本轮没有新引擎或核心能力要求，因此不重复替换引擎或安装依赖。所有新数值是本游戏设计，待真实原画手脚/武器接触与手感校准，不是原作战力排序。

实际只读核对`src/core/moveBuilder.ts`和`src/core/FightSim.ts`后遵守以下限制：

- 人物招式帧仅水平velocity.x实际执行，未填写无效的velocity.y，也未制作持续飞行。
- 飞行道具不继承Move的knockdown、wallBounce、armorBreak，未在道具招式上宣称这些效果。所有durability为1；多发使用不同时刻生成的独立飞行道具，避免一个道具接触数帧连续重复扣血。
- 暗影抓取只在既有抓取框内连接，不拉远处对手、不吸血、不屏蔽对手技能；固定落石不读对手坐标。
- 雷利的迎击是主动出招加短暂无敌，不是新造自动反击系统；剑面弹返仅反射真实飞行道具。有限闪避消耗33气，窗口结束后的收招可受击。
- 七角各26招：9快捷技能 + 站蹲空A/B/C/D共12招 + 方向重击、地空吹飞、前后投共5招。普通技使用各角的武器、长度、轻击速度和伤害参数；技能结构另行区分。
- 所有招名在本轮统一按“本游戏演绎/暂名”管理。没有进行逐项原作出处检索，即使名称熟悉也不在此伪称已查得官方出处；洛克斯全部招名尤其不得对外写成已知原作技能。

## 文件与集成接口

每角分别输出 `src/characters/<id>/{def,moves,animations,ai}.ts`，导出 `<id>Def`、`<id>Moves`、`<id>Anims`、`<id>Ai`；额外 `<id>RequiredStates`只记录待制作状态。动画表为空，角色quotes也为空，没有捏造动画帧数或角色语音。中央候选登记与需求导出由主代理接入；未动正式registry/UI/audio清单。

## 最小验证记录

- 只运行`tests/core/legendRoster1003.test.ts`，首次33项中32项通过。唯一失败是黑胡子投技断言同时计入抓住事件和伤害事件；核对core分别发出`throw`与`hit`后，修正为唯一伤害事件、精确扣140血、施法者不回血，并验证对手恢复后仍能施放自己的快捷技能。单独复测该项通过。合计33项均取得通过证据，不伪称最后一次又全跑33项。
- 9槽逐角双朝向快捷、双朝向经典输入、耗气不足/空中拒绝、收招不能被下一槽绕过、招式/飞行道具正常结束通过。各伤害技能在设计距离实际命中，17基础技通过真实输入启动并命中。
- 差异机制实际模拟：暗影投只扣一次血/不远距拉人/不禁技能；罗杰与洛克斯有限霸体结束后有脆弱收招；金狮子固定落石位置不随对手距离变化且结束消失；雷利真实反弹贝克曼子弹、闪避按时结束；贾巴与贝克曼多段/多发确实多次命中；上斜弹保持显式有限方向。
- 七角CPU各运行两次480帧固定种子，输入合法且同输入结果可重现，至少造成伤害；调用Cpu.input前后完整sim.state相同，未直接改战斗状态。该测试不是胜率、平衡或真人好玩验收。
- 使用项目tsconfig编译选定28个角色模块和本测试文件（29个入口与必要依赖），TypeScript diagnostics=0。未重复整仓构建、lint或旧角色测试。
- 首次默认沙箱Vitest因esbuild子进程spawn EPERM未启动；针对该命令经审批后运行成功，没有安装新依赖。
