### 起点与变更边界

本次修复开始前，工作区已经移除了 `gen:atlas` 中的像素生成步骤和按 `pixel/` 目录自动覆盖姿势的分支，恢复了设定图图集、单帧待机/走路配置及正式纹理过滤。这些是开始时已有的恢复，不计为本次新增。原始四张 JPEG 一直保留。

修改前已备份 22 个相关文件到 `C:\Users\august\AppData\Local\Temp\one-piece-recovery-20260910-212112`，`manifest.json` 记录相对路径及 SHA256。核对结果：原始四张 JPEG 和恢复后的两张 atlas PNG 与备份一致；重新生成只为图集 JSON 增加来源标记。

本次新增：

- 正式切图只接受明确配置的 `sheet.jpg` / `moves.jpg` 裁切来源；未知姿势或其他来源直接报错，避免静默变成站姿。图集写入 `artSource: concept-sheets`。
- `gen-pixel-kit.ts` 标为未采用试验，只输出系统临时目录 `one-piece-fighter-pixel-study`。已有试验文件保留、不参与正式构建。
- `AGENTS.md` 与 README 固定当前人物基线。后续先展示单角色站立、走路、出拳、受击的正常速度样板，经用户验收后才替换。
- 修正动画测试：单帧人物不再被按四帧待机断言，同时保留多帧循环支持的测试。
- 修复 AI 在同一次命中取消窗口内反复决定续招、重置方向输入的问题；改为每次出招决定一次并继续执行输入序列。实际 `st_c → sp_gatling` 回归用例修复前读取续招 24 次，修复后 1 次且成功出招。
- 修复从出招表用 Esc / K 返回时暂停菜单仍隐藏的问题，并清空返回按键，避免串入菜单操作。

### 剩余限制

走路仍为站姿平移，部分动作共用姿势，尚未达到连续动作美术标准。测试与本机浏览器检查不能代替真实手柄、朋友换边试玩或长期对局的平衡验收。当前完成的是人物恢复和相关回归修复，不把整份升级清单标为完成。
