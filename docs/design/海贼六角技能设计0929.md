# 海贼六角技能设计0929

2026-09-29。本文件只记录海贼组候选战斗数据与制作接口；不是人物美术、语音或实机验收记录。对应总计划为 `docs/十二角色PC扩充计划0929.md`。

## 决策记录

- 保留现有 60 Hz 整数核心，不改旧四角、不注册公开角色。每角独立 `def.ts`、`moves.ts`、`animations.ts`、`ai.ts`，每角 26 招：9 个技能、站/蹲/空各 4 招、前重击、地/空吹飞、前/后普通投。
- 每人只用一个主要形态。凯多平时人形持棒，龙形只作为热息终极的独立画面；不使用持续强化状态。山治的 A/C 按键也执行踢技，按键名称不决定人物打击方式。
- 核心攻击只读取水平位移，不实现招式内主动升空；对空技能是地面向上攻击。投射物按施放者根点生成，不读取对手位置，不追踪。核心飞行道具不继承招式的破霸体、硬倒或墙弹标记，因此不在这些招式上声明对应效果。
- 新数据全部是游戏设计候选值，尚未获得原画接触、正常速度手感或对战平衡证据。大体型按竞技尺度缩至可读范围，不能宣称原作身高还原。
- 复用现有 `normal`、`attack`、`utility`、`throwMove` 与 `Cpu`，不新增依赖或共用核心能力。开源/本机复用调查由总计划统一记录。

## 美术、音频与登记接口

`animations.ts` 暂时导出空的 `AnimTable`，不虚报已存在帧。正式动作必须由本轮实际取得的独立原画与运行清单接入。制作需求包括待机/走退/蹲/跳/落地/跑/后撤/翻滚/防御/受击/倒地/起身/受投/拆投/败北/胜利，以及 26 招的起手、有效、收招和实际抓持阶段；帧数应由真实素材确定，不能复制静帧凑数。

香克斯缺左臂，双朝向必须实际检查解剖；索隆三刀位置与口衔刀一致；山治无拳击或持武器动作；白胡子薙刀、大妈帽剑、凯多狼牙棒必须区分武器攻击框与身体受击框。新角色同时需要对 LABUBU 抱腿、LABUBU 普通投、星星人普通投的条件受投动作，不能用通用受投图冒充。

主代理集成时导入 `<id>Def`、`<id>Moves`、`<id>Anims`、`<id>Ai`。投射物种类由各 `moves.ts` 的大写 `<ID>_PROJECTILE_KINDS` 显式列出（山治没有投射物）。资源、技能 FX、对白/字幕、教学、预取与发布白名单必须对应真实采用文件补齐；本组不修改中央登记。
