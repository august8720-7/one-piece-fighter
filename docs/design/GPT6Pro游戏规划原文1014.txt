对，你要的是**“这款游戏究竟怎么设计，23个人怎么做成一款统一、好玩的游戏”**，不是素材包说明、入口排查或者一堆修图要求。

上一轮显示的《现状素材说明1013》《入口问题说明1013》只是参考资料，不是规划交付。我把参考资料和交付结果混在一起了，这是我的问题。

下面直接给总体规划。**以你明确的项目条件为基础；所有新增设计都是建议，不代表已经获准修改旧角色或战斗核心。**

# 游戏总体设计规划

## 一、总体判断：做“角色性格驱动的跨界街机格斗”

### 1. 这款游戏应该成为什么

**一款普通玩家容易打出招式，但需要判断才能获胜的跨界格斗游戏。**

它的核心吸引力不是“这里有23个知名角色”，而是：

> **我喜欢这个人物，所以选他；他的动作很像他，所以打得开心；他的打法有值得琢磨的地方，所以愿意再来一局。**

三个环节缺一不可。

只有形象，没有打法，是角色皮肤合集。  
只有九个技能，没有攻防，是轮流放特效。  
只有严格的竞技规则，没有人物表演，又浪费了跨界阵容的优势。

**推荐把角色辨识度放在第一层，爽快反馈放在第二层，攻防深度放在第三层。**不是深度不重要，而是普通玩家首先要看得懂、打得出来，然后才有兴趣研究。

### 2. 现在最需要纠正的，不是某张图，而是四个方向问题

| 主要矛盾 | 明确推荐 |
|---|---|
| “容易上手”，却有九个独立技能需要记忆 | 九技能保留，但每人先教三个核心选择。操作完整开放，学习分阶段，不要求新手一开始掌握全部。 |
| 想要23个人各有特色，却容易复制同一种突进、远程和大招 | 每个人先确定“靠什么赢、最怕什么”，再决定技能。不能先凑九招，再事后解释区别。 |
| 希望人物精致，却被局部修图拖住整体进度 | 正常速度下的身份、接触和动作可读性严格验收；不影响游玩的毛发、衣纹和局部像素差异进入打磨清单。 |
| 希望快速扩充，却还没有稳定的完整交付方法 | 先完成一个七人里程碑：旧四人＋青雉、香克斯、白胡子。用它跑通普通体型、单臂、大体型和潮玩兼容，再扩充23人。 |

**最重要的制作原则：每个人首先是一套有性格的打法，其次才是一组图片、特效和声音。**

## 二、简明游戏总体纲领

### 1. 背景：一场跨越世界与年代的非正史格斗大会

世界观工作名可以叫**“异想擂台”**，不要求修改现有游戏名称。

设定只需要这么多：

> 一个不属于任何世界、任何年代的竞技场，邀请不同世界的传奇人物与奇妙伙伴参加对决。参赛者保留自己的形象、性格与标志性能力，但遵守同一套竞技规则。这里的胜负只属于这场比赛，不改写他们原本的故事。

这套设定有三个作用：不同年代的人物可以同场；潮玩不需要硬接海贼世界历史；游戏胜负不需要服从原作战力排名。

不需要先写主线任务、阵营战争或者大量过场。**背景负责解释“为什么能打”，角色负责表现“打起来是什么样”。**

### 2. 情绪：对决认真，相遇有趣

热血和爽快是战斗主体，幽默和可爱负责调节情绪。

香克斯对上LABUBU，可以在登场时有一瞬间意外，但战斗开始后仍然认真挥刀。白胡子可以欣赏小对手的勇气，但不能因为对方是潮玩就变成滑稽角色。LABUBU可以捣蛋，但每一下攻击仍要有清楚的发力和接触。

**幽默来自人物反差，不来自战斗规则突然失效。**

### 3. 一局比赛要让玩家经历什么

**试探距离 → 看出习惯 → 抓住空当 → 决定是否花资源 → 出现逆转或终结 → 想重赛。**

九技能应服务这条过程，而不是九个按钮各自独立播放。

人物可以有明显优势，但必须给对方保留游戏空间：强力远程可以有启动和站位代价；高速突进可以有可判断的线路；重武器可以有内圈弱点；反制技可以被延迟或诱骗。

### 4. 统一呈现

| 环节 | 设计目标 | 优先完成的内容 |
|---|---|---|
| 主界面 | 一眼看出“动漫与潮玩同场的格斗游戏” | 主视觉同时出现两类代表；开始游戏最直接，调试入口退到次级位置。 |
| 选人 | 让玩家知道这个人怎么打 | 一句特点、三个打法标签、待机动作、一次确认语音。 |
| 登场 | 快速建立人物关系 | 每人一个短动作、一句短台词；特殊关系替换普通台词，不额外加长。 |
| 战斗 | 角色清楚、危险清楚、结果清楚 | 命中、防御、落空、资源不足的反馈各不相同。 |
| 终结 | 最后一下有分量 | 强调决定性接触、KO与短收束，不默认插入长动画。 |
| 结算 | 保留人物余韵，鼓励再打 | 短胜利动作与台词，重赛和换人方便。 |

舞台、音乐先延续。**优先补命中与防御差异、落地重量、终结收束；新舞台、23首角色主题曲、复杂片头后做。**

## 三、23人角色差异总表

以下是**本游戏的设计定位**，不是当前实现状态，也不是原作战力评定。未核定出处的具体招式一律标为“本作演绎”。

每个角色遵循同一原则：**一个主要赢法，一个辅助办法，至少一个对手能够利用的明显弱点。**

| 角色／核心记忆点 | 打法、节奏与适合玩家 | 优势与对手可利用的机会 | 动作、视听符号与差异 |
|---|---|---|---|
| **路飞：拳头能把距离拉长** | 弹性中近距离进攻；适合主动出手、喜欢连续攻击的人。 | 伸展试探与追击强；长攻击落空后有回收空当。 | 身体拉伸、肩腰回弹、明亮短喝。与卡普区别是“伸缩与连续变化”，不是纯重拳。 |
| **赤犬：不断逼近的熔岩压力** | 稳步推进，迫使对手移动或防守；适合压迫型玩家。 | 正面压力强；大型攻击的方向、落点和恢复必须能被判断。 | 拳势沉、熔岩黏稠、低硬声。区别于青雉的拦截和白胡子的单次震击。 |
| **LABUBU：贴近后就开始捣蛋** | 低位接近、短连段、抱腿；适合灵活主动型玩家。 | 近身节奏变化丰富；手短，接近被读出时容易受阻。 | 身体先收再弹、短肢发力、毛绒触感。与星星人区别是主动闯进去。 |
| **星星人：把对手引向星光落点** | 星形攻击与落点经营；适合预判型玩家。 | 擅长安排空间；布置前后、被贴身时需要承担压力。 | 轻盈起落、清脆星光、温柔短声。不是黄色版LABUBU。 |
| **青雉：先封住你想走的位置** | 中距离控制与反接近；适合耐心玩家。 | 能拦地面路线；预判错误后近身承压，冻结不能无限衔接。 | 动作省、冰形成方向清楚、冷脆碎裂声。与藤虎区别是地面通路控制。 |
| **黄猿：看见线路，下一瞬就到了** | 直线高速进出；适合喜欢抓远处空当的人。 | 爆发接近强；线路和终点被读出后可以惩罚。 | 平时松，启动快；细长光线、从容拖尾语气。区别于山治的连续腿法。 |
| **藤虎：让你不敢随便跳与落地** | 延迟落点、纵向控制、稳守反击；适合计算型玩家。 | 能约束跳跃节奏；延迟威胁发动时，本体不能一直安全。 | 低重心、杖刀小动作引出重压；老年沉稳声。不是紫色冰墙。 |
| **绿牛：攻击像枝条一样延伸过来** | 分段伸展、持续方向压力；适合追着对手改变节奏的人。 | 中距离连续威胁强；伸展起手与回收应暴露节拍。 | 生长方向与连接关系明确、纤维拉扯声。与路飞区别是分段延伸，而非弹性拳头。 |
| **卡普：踏进去，把一拳打实** | 短中距离重拳与位置争夺；适合直接进攻型玩家。 | 近身打击有压迫感；距离不够时必须自己走进去。 | 脚、髋、肩、拳连成发力链；洪亮短喝。不同于路飞的伸缩和凯多的武器扫荡。 |
| **战国：正面稳住，再把你推回去** | 掌势、防接近、正面空间控制；适合稳健玩家。 | 正面守势强；追击和转向不同时占优。 | 双掌、躯干朝向清楚，金色冲击有边界；声音威严完整。大佛用于技能内演出。 |
| **香克斯：你露出破绽，我只需要一刀** | 中距离诱空与精准兑现；适合少而准的玩家。 | 抓失误能力强；持续压制不必最强，挥空有代价。 | 唯一右臂、髋肩带刀、红白细刃；成熟克制声。与罗杰区别是等机会而非连续开路。 |
| **索隆：用多条刀路压满近处** | 中近距离多段斩击；适合喜欢连段和攻势的人。 | 角度变化多；多刀不能等于所有方向同时有效，末段有恢复。 | 三刀连续可追踪、低重心扭腰、交叉刀声。区别于贾巴的左右交替拍点。 |
| **山治：脚步不停，腿法换着来** | 地空衔接、追击与角度变化；适合移动进攻型玩家。 | 连续踢击与转换强；落地、对空失误、长腿技回收有机会。 | 支撑脚与髋部可信、踢击干脆、语气利落。区别于黄猿的单次直线爆发。 |
| **白胡子：尊重他面前这片距离** | 长柄守距离，近身重击补内圈；适合重决策玩家。 | 长距离覆盖强；被进入武器内圈后不舒服，大招恢复明显。 | 宽肩稳步、长柄重量、震裂声；老年低厚声。与凯多区别是控距离而非追着打。 |
| **大妈：多种威胁轮番上桌** | 本体重击与火、雷等技能演出交替；适合布置攻势的人。 | 威胁类型丰富；切换有节拍，不默认多个自主单位持续进攻。 | 夸张但稳定的本体动作、不同材质音色、强情绪起伏。区别于战国的秩序感。 |
| **凯多：逼近后用重击让你做选择** | 重武器突进与近身压迫；适合进攻型大体型玩家。 | 逼近后的威胁强；猛冲被读出可防范，不能全程无条件抗打。 | 肩背带狼牙棒、扎实踏地、钝击与雷光。龙形只作短技能演出。 |
| **黑胡子：把你拉进危险，也暴露自己** | 引入近身、压制与震动兑现；适合高风险玩家。 | 能改变双方距离；吸引不是自动抓住，失败应受罚。 | 向内流动与向外震裂区分，粗哑张扬声。不是另一个白胡子，也不按原作身份制造巨大克制。 |
| **罗杰：不等你站稳，就接着进攻** | 踏步斩击、主动抢节奏；适合持续前压玩家。 | 能不断制造防守选择；前进承诺大，不能随意无成本撤销。 | 宽阔刀路、身体随刀推进、豪放厚亮声。与香克斯形成“主动开路／精准惩罚”差异。 |
| **洛克斯：让你猜错下一拍【演绎】** | 建议做变节奏压迫者；适合进阶玩家。 | 通过停顿、延迟和抢拍制造判断错误；分支必须存在真实空当。 | 具体造型服从核定版本，动作节拍突变、声音危险而克制。不默认黑暗能力。 |
| **金狮子：剑腿从不同高度切入** | 短时升空、斜向攻击；适合纵向变化型玩家。 | 攻击角度特殊；空中路径、落点清楚，不无限悬空。 | 剑腿支撑连续、斜向刀路、张扬声线。与藤虎区别是自己改变角度，而非控制对方落点。 |
| **雷利：省去多余动作，专门拆你的进攻** | 短步、防反、近中距离拆解；适合耐心判断型玩家。 | 防守转进攻强；反制猜错应被投、被延迟或被诱骗。 | 小幅侧身、短刀路、温润老年声。与香克斯区别是连续拆解，而非一次爆发。 |
| **贾巴：左右交替，把人逼进节拍【演绎】** | 双斧交替、紧凑推进、停顿重斩；适合节奏型玩家。 | 两侧交替压力强；第一斧落空或末斧被挡后有机会。 | 左右承重交换、斧击顿挫、豪爽干脆声。不是索隆换两把斧。 |
| **贝克曼：不浪费子弹，也不浪费动作【演绎】** | 定点射击、近身自保、射后重新站位；适合克制型远程玩家。 | 中远距离精准；枪口方向、射后整备与近身空当明确。 | 动作少、停顿准、枪声短、低声短句。与黄猿区别是射击节奏而非高速移动。 |

**“演绎”是对本方案原创功能的标记，不是对原作最新公开情况的判断。**后续制作时，造型、武器和招式出处单独核定。

### 两类平衡问题必须提前定规则

**大体型的强大感靠范围、承重和命中表现，不靠同时获得最快启动、最强防御和最高伤害。**白胡子、凯多、大妈、战国必须分别偏向控距、逼近、轮番威胁和正面稳守。

**潮玩的小体型是形象特点，不是隐含的普攻免疫。**哪些招式能打中站立、蹲下和倒地角色，要按实际对局检查，不能直接把透明图外轮廓当全部判定。

## 四、统一动作、技能与声音规范

### 1. 动作：统一状态，保留不同身体语言

所有角色共用同样的状态含义，但动作不能全部套同一副骨架。

| 动作部分 | 必须统一 | 必须个性化 |
|---|---|---|
| 待机、防守 | 根点稳定，能分清是否防守 | 重心、手的位置、警戒程度、呼吸幅度 |
| 前进、后退 | 真实支撑、左右腿交替，不能整个人滑行冒充走路 | 步幅、抬脚、肩髋摆动、谨慎或进攻感 |
| 跳跃、落地 | 身体尺度连续，起跳与落地状态清楚 | 蹬地方式、收腿方式、落地重量 |
| 攻击 | 起手、有效接触、收招对应战斗状态 | 发力链、攻击轨迹、速度反差 |
| 受击、倒地、起身 | 接触方向可信，不旋转整张站姿图代替倒地 | 失衡方式、承重、潮玩软弹性、武器保护 |
| 投技、受投 | 尝试、连接、保持、释放清楚 | 抓哪里、怎样发力、武器怎样安置 |
| 登场、胜负 | 不干扰正常流程 | 人物性格、关系、幽默与可爱 |

一个动作必须在**关闭特效后仍能辨认**：这是拳、踢、横扫、上挑，还是身体撞击。特效负责增强动作，不负责遮盖没有画出来的动作。

### 2. 九技能：按“3＋3＋2＋1”组织理解，不擅自改费用

建议每人的九技能分为：

| 层级 | 设计作用 |
|---|---|
| 三个核心选择 | 新手先学会：主要进攻、处理接近或跳入、一个招牌选择。 |
| 三个性格选择 | 强化这个人物的距离、节奏、反制或特殊攻势。 |
| 两个资源选择 | 一个偏“抓住机会后提高收益”，另一个偏“改变位置或节奏”。 |
| 一个终结选择 | 高投入、高辨识度、有明确防范和失败结果。 |

这是**功能与教学组织法**，不代表自动把旧技能改成新的资源价格。

每招必须回答：

> **我为什么此刻按它？对方猜对之后，怎样反过来惩罚我？**

九技能不能只是九种伤害，也不能强迫每个人都拥有远程、突进、无敌反制、指令投和全屏攻击。

两个技能若在距离、节奏、结果、资源用途、对手应对上几乎相同，就必须重新解释其必要性。解释不清，才提交调整建议，而不是直接修改旧招。

### 3. 各类攻击的视觉语法

轻攻小幅准备、短轨迹、短反馈；重攻有明显承重或后摆，命中更重，回收也更明显。

远程要看得见发射点和路线。突进要看得见移动方向与结束位置。防反必须区分准备、成功、失败。投技必须真实连接双方。终结技可以夸张，但不能无论是否命中都强播“已经打中”的演出。

**快招不必全部能够看见后再反应，但重招、长距离突进和延迟落点，应给玩家足够的信息做预判。**

### 4. 接触、体型与画面标准

**逻辑站位、受击范围、攻击范围和人物图像是四件事。**图像要解释判定，但不能简单把四者绑成同一个矩形。

普通体型、大体型、潮玩优先建立体型适配模板；单臂、三刀、剑腿再加特殊约束。投技按“投法类型＋受方体型”管理，不为每个组合从零发明坐标，也不能硬套一个手点解决所有人。

香克斯只有唯一右手。抓持前后的刀必须有去处，不能同时持刀又凭空多手抓人。索隆三刀必须连续可追踪。金狮子的支撑点不能在动作中变成普通鞋。

画面统一以下标准：

| 项目 | 标准 |
|---|---|
| 镜头 | 延续已确认的2D侧视略前3/4方向与当前舞台镜头。 |
| 比例 | 同一人物各动作同尺度；蹲、跳、倒地不按格子重新撑满。 |
| 脚底与根点 | 明确记录；裁切透明边不得改变站位。 |
| 非对称人物 | 左右朝向分别检查，不能把水平翻转直接视为合格。 |
| 背景 | 真正透明RGBA，无画进图里的棋盘、灰底、地板或投影。 |
| 画幅 | 可以有站姿、宽幅、长武器等不同规格，但人物尺度不变。 |
| 特效 | 攻击主体、接触反馈、装饰尾迹分层；尾迹不能暗示不存在的持续判定。 |
| 遮挡 | 普通战斗中不能长期盖住脸、脚下位置和抓持点。 |

**可复用的是合格状态、导入规则和不改变身体关系的局部效果。必须重画的是实际关节、承重、握持、前后脚和攻击方向发生变化的姿势。**

不能把前投图平移一下当后投，把同一条前腿镜像一下当完整步态。

### 5. 声音：五套系统，不是一堆音频

| 声音类别 | 主要职责 |
|---|---|
| 人物台词 | 表达性格、态度和关系 |
| 无词出力、受击 | 表达身体用力、失气和痛感 |
| 技能与接触音效 | 告诉玩家攻击材质、方向和是否命中 |
| 系统播报 | 回合、开战、KO、胜负 |
| 背景音乐 | 保持比赛情绪与连续性 |

每个角色先锁定一张声线卡：**年龄感、音色、音高范围、语速、情绪、发声习惯、禁止出现的表现。**

例如，青雉是成年中低声、平缓、少用力；香克斯是成熟温和、留有余裕、发力时短促；白胡子是老年低厚、慢而有分量，但不是每句咆哮。LABUBU和星星人沿用已确认原创声音，不重新追求另一种“更像”的声音。

### 6. 什么事件需要说话

| 事件 | 首版声音要求 |
|---|---|
| 选人确认 | 一句短台词；光标经过不连续触发 |
| 登场 | 一句普通台词；关系台词替换，不叠加 |
| 普通攻击 | 少量短出力变体，不要求每击都发声 |
| 常用技能 | 短喝、关键词或音效即可，不必九招九句完整话 |
| 资源技、终结技 | 保留最有辨识度的喊招与表演 |
| 轻受击、重受击 | 分强弱，连段限频 |
| 倒地、KO | 落地音与失力声配合，避免重复三四层人声 |
| 胜利 | 一句人物表达 |
| 移动、正常待机 | 默认不说话 |

**同一角色同一时刻只保留一条人声。**过期喊招直接丢弃，不排队到两秒后再播放。KO、受击与重要结果有明确打断规则；命中声音不能被长台词盖住。

无词喘息、出力、受击的“语言”可以填“不适用”。验收重点是自然、短促、合适，不是自动转写出了什么字。

基于你已说明的CustomVoice能力，先验证每个声线在“平静说话、喊招、短出力、受击、KO”之间是否一致。**一条日语句子正常，不代表整个人物配音通过；也不把当前模型当成已经拥有任意声线设计和克隆能力。**

## 五、四个代表角色怎样落地

以下技能名称均为**功能工作名**，不是原作出处声明，也不要求覆盖现有名称或数值。LABUBU部分用于映射旧九技能；映射不上的地方记录为待讨论项，不直接改旧角色。

### 1. 先确定四种不同的动作气质

**青雉：松而不散。**  
站姿不紧张，攻击用少量动作引出清楚的冰形。强项是提前判断，而不是不停甩手放冰。防守失败时要真实失衡，不能始终一副不受影响的样子。

**香克斯：动作少，决定明确。**  
右手出刀，髋肩发力，刀路集中。接触后的短停与收束体现力量，不能靠长时间红雷掩盖身体动作。投技必须解决唯一右手和武器的连续关系。

**白胡子：先站稳，再让范围动起来。**  
大部分长柄攻击体现脚下承重与躯干转动，但近身短击可以紧凑。不能所有动作都慢，也不能为了显大把角色放到看不全武器。

**LABUBU：先缩起来，再突然扑出去。**  
短肢不是成人动作缩小版。蓄势来自身体收拢，进攻来自短促弹出；抓投突出抱腿和低位接触。可爱与打击明确可以同时成立。

### 2. 四人的九技能功能分工

| 技能位 | 青雉 | 香克斯 | 白胡子 | LABUBU旧技能映射目标 |
|---|---|---|---|---|
| **1：核心试探** | 直线冰投：查中距离路线 | 短斩：近处快速检查 | 薙刀直推：长而窄的正前控制 | 短扑：快速抢近身，距离有限 |
| **2：核心攻击** | 冰刀横断：中近距离拦截 | 前踏纵斩：惩罚中距离落空 | 长柄横扫：拦地面接近 | 连拍：贴身连续压力，末段可反击 |
| **3：处理跳入** | 冰棘上挑：斜上对空 | 挑空斩：精准截跳 | 反手挑锋：长武器上向控制 | 翻身上挑：短范围对空 |
| **4：风格选择** | 地面冰脊：预判移动或落地 | 肩撞进身：改变纯剑击节奏 | 踏步砸地：压落地，启动明确 | 低位滑入：比短扑更长，终点明显 |
| **5：风格选择** | 定点反制：读对才有收益 | 架刀反制：失败可被诱骗 | 近身短震：处理柄内压力，不默认无敌 | 抱腿翻摔：处理过度防守 |
| **6：风格选择** | 有代价撤离：重新建立距离 | 撤步回切：退半步诱空再斩 | 近身柄压：逼对手改变防守选择 | 节奏位：核对旧招用途，必须区别于另一种突进 |
| **7：资源兑现** | 冰鸟掠袭：覆盖较长线路 | 爆发斜斩：抓空当后兑现 | 震裂斩：长距离机会转重击 | 资源重撞：一次更明确的撞击收益 |
| **8：资源转局** | 分段冰原：建立地面压力 | 震退：花资源换回空间 | 两拍震击：分时制造不同位置威胁 | 资源翻滚：改变位置与进攻节奏 |
| **9：终结** | 极寒领域：高投入区域兑现，不长期冻结 | 完整终结斩：集中表现一次决定性进攻 | 海震终式：重击收束，不持续晃屏 | 招牌大闹：保持短肢比例，完整结束姿势 |

这里真正重要的不是招式名字，而是区别：

青雉把对手挡在想要的距离；香克斯等错误后出手；白胡子让对手付出接近成本；LABUBU想办法进入近身后扰乱节奏。

**同样叫“突进”，四个人也不应具有相同距离、速度、命中结果和恢复方式。**

### 3. 台词与声音事件示范

下面日语均为**本游戏原创草案**，不标成原作引用；正式使用前还需核对自然度、实际时长与合成表现。

| 角色／触发时机 | 日语原文 | 假名读音 | 中文意思与表演要求 |
|---|---|---|---|
| 青雉，对赤犬登场 | 相変わらず、暑苦しいね。 | あいかわらず、あつくるしいね。 | “你还是这么火气十足啊。”低声、略无奈，不大喊。 |
| 青雉，关键冰技发力 | 凍れ。 | こおれ。 | “冻住。”短、冷、直接，跟随发力点。 |
| 香克斯，对路飞登场 | その帽子、似合ってきたな。 | そのぼうし、にあってきたな。 | “那顶帽子，越来越适合你了。”带一点笑意。 |
| 香克斯，胜利 | 踏み込みは、悪くなかった。 | ふみこみは、わるくなかった。 | “你那一步进得不错。”认可对手，不居高临下长篇训话。 |
| 白胡子，对潮玩登场 | 小さくても、手加減はせんぞ。 | ちいさくても、てかげんはせんぞ。 | “个子虽小，我也不会放水。”宽厚、有分量，不轻蔑。 |
| 白胡子，胜利 | いい目だ。まだ折れてねえな。 | いいめだ。まだおれてねえな。 | “眼神不错，还没服输呢。”低厚，短句落稳。 |

LABUBU保留已确认的「嘿嘿，来追我呀！」和「哈！」。不因为海贼王人物以日语为主，就强行把它改成日语。

四人的无词表演也要不同：青雉短吐气，香克斯克制发力，白胡子低而厚的瞬间出力，LABUBU轻短、有弹性。**这些声音不需要为了标语言而强行塞进词语。**

## 六、可复用的单角色制作任务模板与最小验收

### 1. 单角色任务卡

每名负责人都交同一结构的内容，而不是各写各的提示词。

| 模块 | 必填内容 |
|---|---|
| 角色身份 | 角色、版本、形态、负责人、当前状态 |
| 不可修改项 | 已确认造型、肢体、武器、材质、比例、旧数值、战斗规则 |
| 玩法定位 | “这个角色靠什么赢，最怕什么” |
| 差异说明 | 最容易同质化的两人，以及距离、节奏、结果上的区别 |
| 九技能表 | 功能、输入、资源、起手／有效／恢复、命中／防守／挥空结果、对手应对 |
| 动作清单 | 现有、缺失、可复用、必须重画的动作 |
| 接触与体型 | 普通、大体型、潮玩、左右朝向、中场与墙角适配 |
| 视听要求 | 动作语言、特效层次、声线卡、台词与无词事件 |
| 资产记录 | 版本、路径、来源、原始素材与运行素材对应关系 |
| 验收记录 | 实际入口、正常速度录像、人工试玩、实听、问题与回滚版本 |

### 2. 一个动作任务必须写到什么程度

“画一个重斩”不够。完整动作任务至少包含：

> **动作用途 → 角色当前状态 → 起手、接触、收招的逻辑帧 → 重心和攻击轨迹 → 对手接触位置 → 武器与肢体限制 → 画幅、尺度、根点 → 特效和声音触发点 → 如何在游戏里复现 → 合格与失败示例。**

例如香克斯握踝任务，核心不是“手往左43像素”，而是：在指定保持阶段，唯一右手真实围住对手脚踝，武器处于已约定位置，双方逻辑站位不变，披风不遮住连接，左右与墙角仍成立。

局部坐标可以是任务参数，但不能代替完整动作关系。

### 3. 最小验收清单

| 门禁 | 通过条件 |
|---|---|
| 版本正确 | 正确工程、构建、入口、角色版本一致 |
| 人物正确 | 无关键肢体、武器、脸和服装变化 |
| 基础完整 | 既有移动、攻击、防御、投技、受击、倒地、起身和胜负流程正常 |
| 九技成立 | 九招均可使用；分别检查命中、防守或约定应对、落空与失败 |
| 接触可信 | 不明显脱手、抓自己、穿体；特殊体型与左右朝向通过 |
| 战况可读 | 能区分打中、防住、打空、危险位置与招式结束 |
| 声音合格 | 人工独听与游戏混听通过，无严重错词、拖尾、叠音 |
| 正常对局 | 用正常速度实际打过，不只看训练单招或慢放 |
| 人机与教学 | 人机能表现角色主打法，新手能学会三个核心选择 |
| 可交付 | 旧基线无未授权改变，已知问题清楚，版本可回滚 |

**测试通过不是体验通过，文件齐全不是角色通过。**

“可交付”意味着：普通玩家能够正常选他、理解他、用他打一场完整比赛，对手能看懂并作出应对，结束后能够稳定重赛。

## 七、实施顺序与需要拍板的取舍

### 1. 必须先完成／首版可接受／以后打磨

| 必须先完成 | 首版可接受 | 以后打磨 |
|---|---|---|
| 正式与候选版本分清 | 界面朴素但清楚 | 新片头、复杂菜单动画 |
| 角色定位与九技能分工 | 部分技能共用合格短出力声 | 全技能专属喊招、多套关系台词 |
| 肢体、武器、比例正确 | 少量不影响识别的衣纹差异 | 毛发、衣物次级运动 |
| 正常速度下接触可信 | 用经过验证的体型模板 | 更多低频专属配对动作 |
| 命中、防守、落空可读 | 动画帧数不多但姿势真实 | 更丰富中间帧 |
| 声音限频、打断与重赛清理 | 共用部分底层音色，但表演一致 | 更独立的合成声线 |
| 实际对局、回归、回滚 | 沿用舞台与音乐 | 新舞台、人物主题曲 |

### 2. 分组扩充到23人

| 阶段 | 人物 | 主要目的 |
|---|---|---|
| **基线冻结** | 路飞、赤犬、LABUBU、星星人 | 保护既有成果，建立回归标准 |
| **七人完整里程碑** | 新增青雉、香克斯、白胡子 | 跑通普通体型、单臂、大体型，并与潮玩配对 |
| **扩至10人** | 黄猿、藤虎、卡普 | 验证高速线路、延迟落点与重拳 |
| **扩至13人** | 索隆、山治、雷利 | 验证多刀、腿法与精准防反 |
| **扩至16人** | 绿牛、战国、凯多 | 验证伸展、短形态演出与重武器逼近 |
| **扩至19人** | 大妈、黑胡子、金狮子 | 集中处理多威胁、吸引关系与剑腿空中动作 |
| **完成23人** | 罗杰、贾巴、贝克曼、洛克斯 | 在成熟标准上完成差异化与出处核定 |

已有候选可以依据真实完成证据前移，不按文件数量抢位置。

建议同时进入重制作的角色最多两名。其余角色可以并行做资料、技能设计、台词和素材盘点，避免一起抢占生成、集成与验收资源。

### 3. 谁负责什么

角色负责人负责“这个人像不像、打法是否成立、素材是否完整”。统一负责人负责战斗规则、坐标标准、公共特效、音量体系、版本集成和正式发布资格。

AI agent可以并行制作、整理和自测，但必须交出**素材、验证证据、已知问题**。不能让生成者一句“已完成”直接变成验收结论。

你应主要看正常速度代表对局、关键问题和设计取舍，不再承担每一张图的第一轮纠错。

### 4. 反复失败时，改变方法，而不是增加提示词

同一问题连续三轮没有实质改善，就重新定位：

姿势没变，改用明确关节和支撑参考；图里正确、游戏里错误，检查裁切、根点和缩放；披风遮挡，改局部层次；短声总被读成奇怪文字，换表演策略或采用已合格短样本；单独声音正常、实机很吵，改调度与混音。

**每次返工只解决一个可复现问题，不顺手推翻已经通过的脸、比例、服装和动作。**

本机工作分生成、集成、验收三个阶段。本地重推理不与性能验收同时进行；正常对局检查只保留正确工程和必要工具；录像与不录像分别检查，避免混淆资源负载与游戏问题。

### 5. 三项关键取舍

| 取舍 | 推荐 | 最强反方与代价 |
|---|---|---|
| 先七人完整，还是23人一起铺开 | **先七人完整**，23人设计与进度继续保留 | 反方是大阵容更有吸引力。代价是短期选人数量增长较慢，但能避免23人一起返工。 |
| 是否采用体型模板与正常速度容差 | **采用**，身份和明显接触错误仍严格阻断 | 反方是专属配对更自然。代价是首版少量互动不够独特，但不能因此无限修图。 |
| 是否要求23人都有完全独立音色 | **首版不要求**；先保证同角色一致、关键人物可区分 | 反方是共享声线会削弱个性。代价真实存在，但应优先靠表演、节奏和台词区分，之后再扩展声线能力。 |

九技能、旧角色数值与战斗核心继续保留。若普通玩家试玩证明按键负担、技能重复或某项既定约束确实影响体验，再单独提交变更方案，说明收益、最强反方、回归范围和回滚方式。

## 最终要抓住的一条主线

**这款游戏不是“做出23套素材”，而是“做出23种玩家愿意反复体验的战斗性格”。**

青雉让人想预判，香克斯让人想抓破绽，白胡子让人想守住距离，LABUBU让人想贴近捣蛋。动作把这种性格画出来，技能把它变成选择，声音把它变成情绪，实际对局证明它是否好玩。

**下一阶段的成功标志，不是又生成了多少张图，而是七个人都能按照同一套方法，完整、稳定、有区别地打完一场比赛。**
