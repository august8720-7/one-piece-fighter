# One Piece Fighter

本地网页版海贼王 1v1 格斗游戏（玩法参考拳皇）。角色：路飞、赤犬；支持人机、本地双人和训练。

- 规划与设计：`docs/PLAN.md`
- 项目约定：`AGENTS.md`

## 在线游玩与源码

**[点击直接玩2.0](https://august8720-7.github.io/one-piece-fighter/)** · **[冻结1.0完整动漫版](https://august8720-7.github.io/one-piece-fighter/v1/)**。使用桌面浏览器和键盘，首次加载需要下载人物素材；点击“开启声音”，按 Enter 开始，J 确认、K 返回。支持人机、本地双人和训练。表现卡顿时可用[同画风性能档](https://august8720-7.github.io/one-piece-fighter/?art=anime&scope=full&quality=performance)。

2.0默认一键技能，P1使用Q/E/R/F/G/Z/X/C/V，技能栏显示招名、耗气和不可用原因；选人时按重拳U可切回经典搓招。本地双人分别选择模式，全部技能可改键。详见[2.0键位与回退说明](docs/2.0键位与回退说明0922.md)。

公开仓库的 `main` 保存源码、测试、占位图、设计和来源记录；`gh-pages` 保存线上所需的完整运行素材与编译脚本。原图、失败稿、源音频包和本地验收录像不发布。只克隆 `main` 仍不会取得正式视听素材。

源码开发使用 `npm ci`、`npm run dev`；完整动漫模式还需恢复本机素材。`开始游戏.cmd` 只启动既有 `.local-releases/操作演出-0922/playable/` 构建，不会自动生成或下载它。正式素材及旧回退构建继续保留在原电脑，当前结果见[2.0实施与验收](docs/2.0实施与验收0922.md)。

## 运行

双击根目录 **`开始游戏.cmd`** 打开2.0；**`开始1.0经典版.cmd`** 打开冻结0915完整动漫版。旧像素版请使用 **`开始旧版游戏.cmd`**，它不是1.0动漫回退。游玩时保留启动窗口；已有相同构建服务时会直接打开现有游戏。

命令行启动2.0：`node scripts/playCandidate.mjs --release candidate-0922 --full`，地址为[2.0完整动漫标题](http://127.0.0.1:4180/?art=anime&scope=full&quality=high)。冻结1.0使用 `--release classic-1 --full`（4181端口）；0915、0914、0913原构建分别使用 `--release candidate-0915 --full`（4179端口）、`--release candidate-0914 --full`（4178端口）、`--release candidate-0913 --full`（4177端口）。`体验新版样板.cmd` 仍是内部样板训练入口；正常游玩使用“开始游戏”。启动器只使用已有本地构建，不安装依赖、不自动构建。

开发运行：

```
npm install
npm run dev        # http://localhost:5173
```

## 验证

```
npm run typecheck && npm run lint && npm test && npm run build
```

## 模式与素材

完整动漫候选与保留旧版共用格斗底座和模式。动漫人物由 `scripts/anime_manifest.json` 和 `build_anime_atlas.py` 生成独立 `anime/` 图集，已覆盖全部现有状态与招式；旧正式图集保持可回退。`scope=full` 进入完整分支，未指定完整范围的样板入口仍按自身边界运行。

- 打开 `http://localhost:5173/` 从标题进入；菜单提示随当前键位更新，默认 A（J）确认、B（K）返回
- 直达（开发用）：`?mode=versus|cpu|training&p1=luffy&p2=akainu&difficulty=easy|normal|hard&tutorial=1`
- 训练：无限血气；F5 木桩（含出拳）、F6 位置重置、F7 / F8 气/血、F4 精灵/色块、F9 慢放、F10 逐帧、F11 出招表、F12 跳过引导。引导六步：走 / 轻 / 重 / 防 / 特殊技 / 短连。F1～F3 调试面板需手动开（默认关）
- 暂停可进出键位设置而不重开对局；出招表分类列出完整普通技、空中/投技、特殊技和超必杀，按当前朝向和键位显示。训练暂停及完成六步引导后可直接“挑战 CPU”，保留角色和难度
- 无小键盘时，设置里选「P2 无小键盘」（方向键 + N M , .）
- 音频：任意键或点击后解锁；M 静音；键位设置里可调音量（写入 localStorage）
- 旧版角色图集：`npm run gen:atlas`（需要 Python 3 + Pillow）按 `scripts/sprite_manifest.json` 的来源哈希、裁切、锚点与派生处理生成 `public/assets/characters/<id>/atlas.png + atlas.json`。源表和图集只在本地，不进 Git；来源缺失保留现有图集，哈希或坐标非法则报错。
- 旧版保留《Gigant Battle!》系列连续精灵和已批准的两年后路飞造型。完整动漫候选使用Image 2.5人物原画、显式后处理和独立图集；来源、失败稿与处理证据保留，不用旧像素图冒充新动作。
- `placeholder.*` 和色块回退仅适用于旧版素材路线。请求新版但必需资源损坏时明确报错、重试或主动进入旧版，停止自动切回像素人物；详细纹理和加载信息在按需诊断中查看。

## 部署

Vite `base` 已是 `./`，白名单运行包支持子路径静态托管。当前正式素材只能在原电脑恢复，单独从 `main` 克隆后构建不能得到完整动漫版。

当前提速版需先按 `docs/assets/网络素材编码0915.md` 恢复并生成网络素材，再显式指定新的候选目录，保留旧 `dist/`：

```
npm run build -- --mode delivery --outDir <新的候选目录> --emptyOutDir false
node scripts/packagePages.mjs <已验收候选目录> .local-releases/加载提速-0915/publish
```

当前 GitHub Pages 使用 `gh-pages` 分支根目录；先上传内容哈希素材，通过线上校验后再切首页。`packagePages.mjs` 只从指定的已验收候选提取运行文件并校验 SHA256，默认参数仍保留历史0913行为；脚本不构建、不自动推送。使用新版本时应明确传入候选路径，流程与当前发布包见[加载提速交付](docs/加载提速交付0915.md)。

本项目为海贼王同人学习项目，无官方关联。2026-09-14 用户已授权公开仓库与可玩运行包；此部署不表示角色形象或原声音频获得了商业授权。只有显式清单中的本地源文件齐全时才能重新生成正式人物。
